# Anomaly Detection

Finds faulty machine sensor readings (temperature and vibration) with Isolation Forest, an unsupervised algorithm that never sees the fault labels.

## What you'll learn

- Unsupervised anomaly detection
- Isolation Forest and the contamination parameter
- Ranking readings by anomaly score

## How to run

```bash
git clone https://github.com/Ddharsh1707/anomaly-detection.git
cd anomaly-detection
pip install -r requirements.txt
python main.py
```

No dataset download needed: the data is built into scikit-learn or generated by the script.
